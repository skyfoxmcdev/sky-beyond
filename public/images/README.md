# Illustrations du monde

## Provenance

Les fichiers de ce dossier sont des **illustrations voxel originales** créées pour Sky & Beyond et
reprises du site existant du projet. Le fichier `CREDITS.md` du projet source précise qu'aucune
photographie de stock, aucune capture de jeu et aucune image externe n'ont été utilisées.

Elles **ne sont pas des captures du serveur Minecraft**. Ce sont des interprétations de l'archipel,
utilisées comme direction artistique. Chaque apparition importante est signalée dans l'interface
par la mention discrète « Illustration originale » ou « Illustration ».

Aucune capture officielle du serveur n'a été fournie pour cette livraison. Aucun faux screenshot
n'a été fabriqué.

## Fichiers

| Fichier | Usage principal |
| --- | --- |
| `hero-archipelago.webp` | Image principale du hero, plein écran |
| `archipelago-wide.webp` | Vue large de l'archipel |
| `islands.webp` | Manifeste et carte « îles / ressources » |
| `cover-dawn.webp` | Couverture de la note d'ouverture, carte ressources |
| `cover-night.webp` | Couverture de note, ambiance nocturne |
| `npcs.webp` | Carte « présences » / gardiens |
| `airship.webp` | Appareil, univers aérien |

## Règles d'intégrité visuelle

- Ne pas présenter ces images comme des captures en jeu, dans un alt, un texte ou un partage social.
- Ne pas ajouter de HUD Minecraft, de faux joueurs ou de faux compteurs par-dessus.
- Ne pas utiliser une image trouvée en ligne comme si elle représentait le serveur.
- Si le propriétaire fournit de vraies captures, les placer ici, mettre à jour le composant et
  l'alt, et retirer la mention « Illustration originale » pour ces images précises.
- Conserver les images optimisées (WebP/AVIF) et des dimensions raisonnables ; `next/image` gère
  les variantes responsives et le lazy loading.
